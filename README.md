# Rafael · JZ — English version

Personal static website in English, built with HTML, CSS, and JavaScript. Local images are stored in `assets/`.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub Pages will show the website address on that page when deployment is complete.

You can also open `index.html` directly in a browser to preview it locally. The site uses Google Fonts when online; all other website files and images are local.
